What should the public dashboard feel like?

Below: how to read it, then three directions, built from today's real 6-target run: 24 signals flagged, none survived. Click any you like; you can pick more than one. The real site covers all 1,133 stars.

How to read everything below

1 · What a cadence is

Each 5-minute look at the star alternates with a look somewhere else. A real signal from the star should follow the telescope.

2 · The three fingerprints
From the star
every ON, no OFF
Interference
there wherever we point
One-off
one scan, then gone

Bar height is signal strength in each scan. The red dashes mark the detection line. Only the first pattern counts.

3 · The ladder, in order
  1. 1Seen in any OFF scan → eliminated
  2. 2Missing from any ON scan → eliminated
  3. 3Doesn't drift (Earth-fixed) → eliminated
  4. 4Inside a known interference band → eliminated
  5. 5Also seen around another star → eliminated
  6. ✓Passes all five → candidate

Every flagged signal goes down the same five rungs. The dashboard records the first rung that eliminated it.
